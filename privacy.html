Privacy Policy

Area55 Backup · Last updated: 19 October 2026

Area55 Backup ("the tool") is a private script used by a single person, the owner of the Area55 business application, to back up that application's own data to the owner's own Google Drive. It is not a public service.

Information the tool accesses

  • Google Drive. The tool asks for the https://www.googleapis.com/auth/drive.file permission. With it the tool can create, read, update, and delete only the files and folders that it created itself. It cannot see or change any other file in the Drive.
  • The owner's own application data. The tool reads the owner's database and file storage in order to copy them. This data belongs to the owner and is not data about visitors or about other Google users.

How the information is used

The information is used only to create backup copies in a folder of the owner's Google Drive, and to delete backup copies after they reach a set age. Backups are encrypted before they are uploaded.

Sharing and storage

  • The tool does not sell, rent, or share any information with third parties, and does not use it for advertising or analytics.
  • Google user data obtained through the Drive permission is used only to provide this backup function. It is not transferred to anyone else, and it is not used to develop, improve, or train any machine-learning or artificial-intelligence model.
  • The tool has no users other than its owner and keeps no database of personal information. Access credentials are kept as encrypted secrets in the owner's private code repository settings.

Your choices

The owner can revoke the tool's access to Google Drive at any time at myaccount.google.com/permissions, and can delete the backup folder from Google Drive at any time.

Changes

If this policy changes, the new version will be published on this page with an updated date.
