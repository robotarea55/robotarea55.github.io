Area55 Backup

A private backup tool for a single owner.

Area55 Backup is a small automated script used by one person, the owner of the Area55 business application, to keep a copy of that application's own database and uploaded files.

Once a day the script copies the owner's data to a folder in the owner's own Google Drive. The copies are encrypted before they are uploaded. The tool asks Google for the narrowest Drive permission (drive.file), which only allows it to see and manage the files and folders that it created itself. It cannot read any other file in the Drive.

This tool is not offered to the public, has no sign-up, and does not collect, sell, or share data about any visitor or other person.
